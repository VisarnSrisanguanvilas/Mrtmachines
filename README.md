## 📖 Overview

This is a **practice project** created to learn and experiment with full-stack development. It simulates the user interface and basic logic of an MRT Ticket Vending Machine (TVM), including station selection, ticket calculation, and a simple management backend.

*Note: This is a simulation for educational purposes only.*

## 🛠️ Features

- 📍 **Station Selection**: Simple interactive map/list to select origin and destination.
- 🎫 **Ticket Simulation**: Calculation of fares and mock ticket issuance.
- ⚙️ **Basic Admin View**: A simple interface to check machine status and transactions.
- 🌐 **Full-stack Integration**: Connecting a Next.js frontend with a FastAPI backend.

## 🚀 Tech Stack

- **Frontend**: Next.js (App Router), Tailwind CSS
- **Backend**: FastAPI (Python), SQLModel
- **Database**: SQLite (Local file)

---

## 🛠️ How to Run

### Backend
1. Navigate to `MRTBackend`
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python main.py`

### Frontend
1. Navigate to `MRT Frontend1/mrt`
2. Install dependencies: `pnpm install`
3. Run: `pnpm dev`
